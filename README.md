# arithmetic_operations.c
Prompts the user to enter two numbers.
Stores input values in variables a and b (type: float).
Performs four operations:
Addition (a + b)

Subtraction (a - b)

Multiplication (a * b)

Division (a / b, only if b != 0)

Uses printf with formatting to show results up to two decimal places.
Displays an error message if division by zero is attempted.
